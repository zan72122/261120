# しゅわーっ！パパのシャツにアイロン

## 起動方法
- `index.html` をそのまま開く（file:// でも、Pages のサブフォルダでも動く。読むのは同じフォルダの中のファイルだけ）。
- 作り直すとき: `node tools/build.mjs`
  - `index.html`（約 4KB）… 待ち画面（最初の場面の写真 `poster-*.jpg`）を出してから、下の JS を順に読む。
  - `vendor/three.min.js` → `game.js`（最初の場面に要る部品: common, core, env, shirt, iron, acorn, audio, flow）。
  - `late.js`（パパ）… 最初の絵が出た後に裏で読み、ドラッグしていない時に作る。ハンガーの場面に来たら待たずに作る。
  - 開発用に 1 ファイルへまとめる時は `--out X.html`（パパも最初から入る）。
- 待ち画面の写真を作り直す: `node tools/build.mjs && node tools/poster.mjs && node tools/build.mjs`
  （見た目を変えた時。シャツは周ごとに色が変わるので写さず、空のかごの絵にしてある）

## 起動を速くするためにしていること
- 写真はかごの場面から始まる時だけ出す（保存からハンガー・どんぐりの場面に戻る時は無地の待ち画面）。
  最初の絵の 2 枚目を描いたら 0.45 秒で消える。読み込みが長い時だけ、下に小さな点が 3 つ揺れる。
- シェーダは最初の絵に映る物の分だけ作って絵を出し、隠れている物（どんぐり・湯気・パパ）は後から裏で作る
  （core.js `app.warm`。KHR_parallel_shader_compile があれば compileAsync、無ければ普通に compile）。
- テクスチャ作りのノイズは格子点の値を覚えて使い回す（common.js `G.noise2`、env.js `pnoise`。結果は同じ）。
- シャツのしわ模様は reset が続けて呼ばれても最後の 1 回だけ作る（shirt.js `flushWrinkles`。模様は以前と同じ）。
- パパとどんぐりの共通の道具は acorn.js にあり、`G.papaKit` として papa.js に渡す。

## 遊びの流れ
かごのシャツをマットへ → アイロンでしわを消す（ポケットの「こつん」でどんぐり）→ アイロンを台へ →
どんぐりをポケットへ → シャツをハンガーへ → パパが着て出てくる → ポケットをとんとん → 次の色のシャツ。

## 確認したこと（390×844、ヘッドレス Chromium）
- 読み込み・開始時のコンソールエラーなし。
- 実際のポインタ操作で最初から最後まで 1 回通し、次の色のシャツがかごに入るところまで進むこと。
- 各場面で「次に触る物」が身じろぎ・光だまり・構図で示され、放置 7 秒で半透明の指のお手本が出ること。
- パパの場面で、カメラが首より上（頭のない所）を映さず、床より下にもぐらないこと。
- WebGL が使えない時に、埋め込みの静止画の代替画面が出ること。

## 描画の負荷（iPhone / iPad 向け）
- 影マップは毎フレーム描かず、影を落とす物がそのライトの範囲で動いた時だけ描き直す（core.js `makeShadowCache`）。
  シャツのように頂点シェーダで形が変わる物は `mesh.userData.shadowSig(arr)` に形を決める値を積む。
- 描画解像度は端末倍率（最大 2）と画素数上限 約 260 万の小さい方。iPad の大画面で塗りが重くなりすぎない。
- 48fps を切る状態が続くと解像度を 1 段ずつ下げ、効かなければ（省電力モードの 30fps 固定など）元に戻す。余裕が続けば戻す。
- 隠れている物（パパなど）のシェーダは最初の絵の後に裏で作っておき、登場の瞬間に止まらないようにした。
- 湯気の粒が無い間は描画も GPU への転送もしない。ポケットの縫い目は動くたびに GPU バッファを作り直さない。

## 既知の問題
- 実機（iPhone / iPad）と音は未確認（ヘッドレスでは音が鳴らないため、エラーが出ないことだけ確認）。
- 横向きでは、ハンガーの場面で部屋の壁の端が左右に見えることがある。
- 白・ピンクのシャツは、青・緑よりしわが少し見えにくい。
- パパのズボンの股に、寄りの画面で少し不自然な折れ影が残っている。
- ドラッグ中の画面回転・連打・非表示からの復帰は、作りとしては対応済みだが個別には試していない。
