# しゅわーっ！パパのシャツにアイロン

## 起動方法
- `index.html` をそのまま開く（file:// でも、Pages のサブフォルダでも動く。外部読み込みなし）。
- 作り直すとき: `node tools/build.mjs`（`vendor/three.min.js` と `src/*.js` を 1 ファイルにまとめる）。

## 遊びの流れ
かごのシャツをマットへ → アイロンでしわを消す（ポケットの「こつん」でどんぐり）→ アイロンを台へ →
どんぐりをポケットへ → シャツをハンガーへ → パパが着て出てくる → ポケットをとんとん → 次の色のシャツ。

## 確認したこと（390×844、ヘッドレス Chromium）
- 読み込み・開始時のコンソールエラーなし。
- 実際のポインタ操作で最初から最後まで 1 回通し、次の色のシャツがかごに入るところまで進むこと。
- 各場面で「次に触る物」が身じろぎ・光だまり・構図で示され、放置 7 秒で半透明の指のお手本が出ること。
- パパの場面で、カメラが首より上（頭のない所）を映さず、床より下にもぐらないこと。
- WebGL が使えない時に、埋め込みの静止画の代替画面が出ること。

## 既知の問題
- 実機（iPhone / iPad）と音は未確認（ヘッドレスでは音が鳴らないため、エラーが出ないことだけ確認）。
- 横向きでは、ハンガーの場面で部屋の壁の端が左右に見えることがある。
- 白・ピンクのシャツは、青・緑よりしわが少し見えにくい。
- パパのズボンの股に、寄りの画面で少し不自然な折れ影が残っている。
- ドラッグ中の画面回転・連打・非表示からの復帰は、作りとしては対応済みだが個別には試していない。
